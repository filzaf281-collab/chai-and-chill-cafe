# ☕ Chai & Chill Cafe

A modern, responsive, and aesthetic cafe web application built with **Next.js 15 (App Router)**, **Tailwind CSS**, and **Framer Motion**.

## ✨ Features

- **Warm Brown & Cream Aesthetic**: Handcrafted theme tuned for a cozy cafe atmosphere.
- **Hero Showcase**: High-resolution Unsplash imagery, dynamic badges, and clear CTAs.
- **Signature Menu**: 6 specialty items (Karak Chai, Zafrani Chai, Cold Coffee, Club Sandwich, Brownie, Fries) with interactive ordering counter, live cart totals, and toast notifications.
- **About Us**: Cozy ambient storytelling and core values grid.
- **Customer Reviews**: Testimonials with star ratings and order badges.
- **Table Reservation & Contact Form**: Fully interactive reservation request form with instant visual confirmation.
- **Responsive Navigation**: Mobile slide-out drawer, cart status pill, and direct section scrolling.
- **Production-Ready**: Built for zero-downtime deployment on Vercel.

## 🛠️ Tech Stack

- **Framework**: Next.js 15.5.x (App Router)
- **Library**: React 19
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Typography**: Poppins (next/font/google)

## 🚀 Getting Started

1. Clone repository:
   ```bash
   git clone https://github.com/<your-username>/chai-and-chill-cafe.git
   cd chai-and-chill-cafe
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
